THE IDEA BEHIND FLOWMORI

Made for the
little things.

A screenshot here. A reference image there. Something you copied and can't find again. A menu bar that's running out of space.

None of these should interrupt your day. Flowmori began as a personal tool to make these small moments a little easier — and grew into an open-source project worth sharing.

GOOD TO KNOW

A few quick
answers.

What is Flowmori?+

Flowmori is a native macOS productivity toolkit bringing screenshots, image pinning, clipboard history, and menu bar organization together.

Is Flowmori free and open source?+

That's the plan. Flowmori is being developed as a free, open-source application. The repository and licensing details will be shared when the project becomes public.

Can I download it now?+

Not yet. The first public build, installation instructions, and release notes will appear here when they're ready.

Which macOS versions are supported?+

Development and testing currently focus on macOS 26. Final minimum version and hardware support will be confirmed with the release.

Why does it need system permissions?+

Screenshots and some menu bar interactions rely on macOS system permissions. The application will explain the permissions needed for each feature.

What happens to my screenshots and clipboard data?+

Flowmori is being designed with local-first functionality in mind. Data storage, permissions, and any network access will be documented before public release.
