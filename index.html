THE IDEA BEHIND FLOWMORI

Made for the
little things.

A screenshot here. A reference image there. Something you copied and can't find again. A menu bar that's running out of space.

None of these should interrupt your day. Flowmori began as a personal tool to make these small moments a little easier — and grew into an open-source project worth sharing.

Before you install

  • This preview uses ad-hoc signing and has not been notarized by Apple.
  • macOS may block the first launch. If you trust the source, allow the app in System Settings → Privacy & Security.

  • Keep Gatekeeper and System Integrity Protection (SIP) enabled.
GOOD TO KNOW

A few quick
answers.

What is Flowmori?+

Flowmori is a native macOS productivity toolkit bringing screenshots, image pinning, clipboard history, and menu bar organization together.

Is Flowmori free and open source?+

Yes. Flowmori is free and open source under the MIT License. You can read, modify, and build the code on GitHub.

Can I download it now?+

Yes. Download v0.1.47 Early Preview from GitHub Releases. This is a pre-release, signed ad-hoc and not notarized by Apple. Read the installation notes below the download button before opening the app.

Which macOS versions are supported?+

The preview requires macOS 26+ and Apple Silicon (arm64). Menu bar organization uses internal system APIs and is verified and enabled only on macOS 26.6.2 (25G83). It is paused on other builds, which need revalidation after OS updates; this restriction does not disable screenshots, image pinning, or clipboard history.

Why does it need system permissions?+

Screenshots need screen recording permission; menu bar organization needs Accessibility. Clipboard access follows macOS authorization. Permissions are independent, so denying one does not disable the other modules.

What happens to my screenshots and clipboard data?+

Screenshots and clipboard history are stored locally on your Mac. By default, the app does not connect to the network, upload data, or send telemetry. See the repository README for storage and permission details, or report a problem via GitHub Issues.
