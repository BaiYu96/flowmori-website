Privacy note

Pre-release information

Flowmori is under development and has not yet released a public build. This page describes intended design principles, not a completed audit or a final product privacy policy.

Our approach

Flowmori is being built with local-first functionality in mind. Its planned features include screenshots, image pinning, clipboard history, and menu bar organization. Some of these features may request macOS system permissions.

Before public release

We will review the actual implementation, storage paths, permission usage, and any network connections, then publish an updated privacy policy that accurately describes how the released app handles data.

About this website

This static website does not include an account system, contact form, or first-party analytics scripts. Hosting and DNS providers may process ordinary request metadata when serving the website.

Questions?

Once our public GitHub repository is available, it will be the primary place to report questions or issues.
