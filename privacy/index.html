Privacy note

Pre-release information

Flowmori is open source under the MIT License and an early preview is available. This page summarizes the current repository documentation; it is not a completed audit or a final privacy policy for a stable release.

Our approach

The app README documents local storage for screenshots and clipboard history, with no network connections, uploads, or telemetry by default. Screenshots need screen recording permission, menu bar organization needs Accessibility, and clipboard access follows macOS authorization. Permissions are independent.

Before a stable release

We will review the actual implementation, storage paths, permission usage, and any network connections, then publish an updated privacy policy that accurately describes how the released app handles data.

About this website

This static website does not include an account system, contact form, or first-party analytics scripts. Hosting and DNS providers may process ordinary request metadata when serving the website.

Questions?
